\section{Behavioral Description}
\label{sec:behavioral_description}

The \blockname\ block supports multiple rounding and overflow modes, including \textbf{truncation}, \textbf{rounding}, \textbf{saturation}, and its variations like \textbf{round to zero} and \textbf{round to infinity}. This approach enables flexibility in adapting to various numerical precision requirements. The choice of rounding mode directly impacts the accuracy and statistical properties of the processed data, such as the block's final PPA, which is particularly relevant in applications such as digital signal processing (DSP) and machine learning accelerators.

This section also describes how the block interacts with input data, processes rounding operations, and produces output values while adhering to specific quantization constraints. Key functional aspects such as overflow handling, signed and unsigned arithmetic support, and configurable precision are highlighted to give a clear understanding of its intended behavior.

Diagrams, flowcharts, and example scenarios are presented to illustrate the rounding process in different configurations, ensuring a comprehensive understanding of the block operation before diving into implementation details in subsequent sections.

\subsection{Overflow Methods}
\label{sec:overflow}
The block supports multiple overflow handling methods for fixed-point arithmetic, ensuring correct behavior when the result exceeds the representable range. These methods are summarized in Table \ref{tab:overflow}, which provides a comprehensive overview of each overflow scenario. The "Description" column of the table offers a high-level explanation of how the block manages data when overflow occurs, including whether values are saturated, wrapped around, or clipped.

        Saturation (\small{SAT}) & The result number gets the sign bit of the original number. The remaining bits shall get the inverse value of the sign bit. In unsigned saturation, the remaining bits shall be set to 1 (overflow) or 0 (underflow).\\ \hline
        Saturation to Zero (\small{SAT\_ZERO}) & All bits shall be set to zero if an overflow occours.\\ \hline
        Symmetrical Saturation (\small{SAT\_SYM}) & The result number shall get the sign bit of the original number.         Wrap-around (\small{WRAP}) & All bits except for the deleted bits shall be copied to the result number. \\ \hline
