\section{Overview}


The \blockname\ block is a combinational module that implements quantization and overflow methods according to the IEEE 1666-2023 SystemC standard \cite{SystemC} for fixed-point arithmetic. It features configurable parameters that enable the selection of quantization and overflow modes, offering flexibility to be applied in different arithmetic precision requirements.
